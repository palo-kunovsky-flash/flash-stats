# Shot list

Five images, in the order the README uses them. Capture with `⌘⇧4` then
**space** for a single window (it includes the shadow), or `⌘⇧4` and drag for a
region.

Save them here with exactly these names:

| file | what it shows | how |
|---|---|---|
| `desktop.png` | the widget where it lives, top right of the desktop | region: the corner of the screen with a little wallpaper around the widget, so it is obvious it sits *on the desktop* |
| `menubar.png` | the two-lane network meter next to the clock | region: a narrow strip of the menu bar, clock included for scale |
| `card-open.png` | one card expanded — Network is the most interesting | window shot of the widget with the Network card open |
| `panel.png` | the panel that opens when the meter is clicked | window shot |
| `settings.png` | the settings window | window shot |

Two things worth getting right:

- **Have something happening.** A widget showing 2 % CPU and an idle network
  says nothing. Start a download or a build first so the graphs have shape.
- **Wallpaper matters** for `desktop.png` — the widget is translucent, and a
  busy photo behind it shows that off far better than a flat colour.

Retina screens produce 2× images. Leave them as they are; the README displays
them at half width and the detail is worth the file size, as long as the total
stays a few hundred KB.
